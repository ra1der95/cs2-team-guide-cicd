# Запрос ИИ-агенту для доработки галереи

В проекте «CS2 Команда» доработай секцию `#team-gallery`. Используй ровно три уже подготовленных локальных файла из `assets/images/`: `team-setup.jpg`, `gaming-pc.jpg` и `keyboard-focus.jpg`. Размести их в трёх карточках галереи, не загружай изображения с внешних серверов. Для каждого изображения укажи точный альтернативный текст и короткую подпись по содержанию фотографии. Сохрани блок авторства Unsplash и существующий адаптивный макет. Проверь относительные пути к файлам и не меняй калькулятор, меню и другие разделы страницы.

Промпт составлен по требованиям ЛР5: изображения из рабочей папки проекта, три изображения, описания и изменение сайта с помощью ИИ-агента.
