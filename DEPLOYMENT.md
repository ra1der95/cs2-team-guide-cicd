# Публикация сайта с GitHub Actions

1. Отправьте ветку `main` в GitHub-репозиторий.
2. Откройте **Settings → Pages**. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
3. Каждый push в `main` запускает `.github/workflows/deploy.yml`: сначала проверку HTML и локальных файлов, затем публикацию на GitHub Pages.
4. Во вкладке **Actions** дождитесь зелёной отметки у шагов `validate` и `deploy`. Откройте URL окружения `github-pages` и проверьте страницу.
5. Измените заголовок в `index.html`, отправьте новый commit в `main`, дождитесь нового успешного запуска и убедитесь, что обновлённый текст появился на сайте.

Пока изменения не отправлены в удалённый репозиторий, адрес GitHub Pages и успешный запуск Actions не подтверждены.
